💧 Designing smarter irrigation through automation and sensing

I designed and built an Arduino-based automated irrigation controller that optimizes water usage using real-time environmental data and structured control logic, while managing the full project lifecycle using Microsoft Project.

🔧 Controls & System Design

Integrated multiple sensors: rainfall, soil moisture, ultrasonic tank level, and temperature

Developed control logic to automatically activate a water pump via relay based on soil and weather conditions

Implemented fail-safes to prevent pump operation during low tank levels or rainfall events

Designed a clear I2C LCD HMI to display live system status and sensor readings

💻 Software & Electrical Engineering

Programmed in C++ (Arduino IDE) using structured, modular code

Designed full wiring schematics and PCB layouts in KiCad

Applied low-voltage design principles to ensure safe and reliable relay operation

Performed systematic debugging and signal validation during integration

Designed and 3D-printed a custom enclosure for environmental protection

📅 Project Management & Execution

Planned tasks, dependencies, and milestones using Microsoft Project

Used Excel for tracking sensor calibration data and testing results

Learned how structured scheduling reduces integration risk and improves build efficiency

📈 Impact

Automated irrigation decisions based on real-time data rather than manual intervention

Reduced unnecessary water usage through condition-based control

Demonstrated integration of embedded systems, sensors, and actuator control for sustainable infrastructure applications
